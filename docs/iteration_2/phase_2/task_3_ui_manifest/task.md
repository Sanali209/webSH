# Задача 2.3: Декларация UI-элементов и Версионирование (Phase 2)

**Цель:** Обеспечить строгую декларацию UI-компонентов (Виджеты, Вьюхи, Ярлыки) в `manifest.json` и контроль совместимости версий API.

## Контекст
*   **Файлы:** `core/schemas.py`, `core/loader.py`, `core/registry.py`
*   **Документация:** `docs/iteration_2/iteration_plan_and_roadmap.md` (Фаза 2)
*   **Библиотеки:** `pydantic`, `semver` (или `packaging`)

## Подзадачи

1.  [ ] **UI-модели (Pydantic)**
    *   Создать в `core/schemas.py`:
        *   `WidgetSchema(id, size, entry_point, title)`
        *   `ViewSchema(id, title, entry_point)`
        *   `ShortcutSchema(icon, title, action)`
        *   `PluginUI(widgets, views, shortcuts)`
    *   Использовать `Literal` для фиксированных размеров (например, `1x1`, `2x2`).
2.  [ ] **Версионирование (`compatibility_version`)**
    *   Добавить поле `compatibility_version` в `PluginManifest` (`core/loader.py`).
    *   **Logic:**
        *   При загрузке плагина (`core/loader.py`), проверять это поле.
        *   Сравнивать с текущей версией SDK (`core.sdk.VERSION`).
        *   Использовать семантическое версионирование (`>=1.0.0 <2.0.0`).
        *   Если несовместимо -> `logger.error` и пропуск загрузки.
3.  [ ] **Unit Tests**
    *   Создать плагин с неверной версией SDK (например, `99.0.0`).
    *   Проверить, что Loader отклоняет его.
    *   Создать плагин с невалидным манифестом (отсутствует `entry_point`).
    *   Проверить, что Loader отклоняет его.

## Автоматические тесты
*   **Integration:** Тест `Loader` с разными манифестами (valid/invalid version/schema).
*   **Unit:** Проверка логики сравнения версий.

## Пункты самопроверки
*   [ ] Манифест с несовместимой версией не загружается.
*   [ ] Манифест с ошибкой в `widgets` (например, `size: 10x10`) не проходит валидацию.
*   [ ] Логи содержат четкие сообщения об ошибках.

## Критерии выполнения (Definition of Done)
1.  Схема манифеста поддерживает UI-элементы.
2.  Валидация манифеста работает строго.
3.  Проверка совместимости версий реализована.
4.  Тесты проходят.
