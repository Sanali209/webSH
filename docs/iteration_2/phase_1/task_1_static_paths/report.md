1.  **Установка зависимостей**:

## Возникшие проблемы и решения:

*   **WhiteNoise и ASGI**: `WhiteNoise` предназначен для WSGI. Для использования с FastAPI (ASGI) потребовалось обернуть его в `WSGIMiddleware` (использована библиотека `a2wsgi`).
*   **Тестирование WhiteNoise**: При тестировании файлы создаются динамически, но `WhiteNoise` индексирует их при старте. В тестах пришлось вызывать `desktop_app.add_files("dist")` для обновления индекса.
