# Задача 1.1: Настройка статических путей и безопасности (Phase 1)

**Цель:** Обеспечить безопасную и эффективную раздачу статических файлов (Шелл, Плагины) через FastAPI с использованием лучших практик (WhiteNoise, CSP).

## Контекст
*   **Файлы:** `core/main.py`, `core/settings.py`
*   **Документация:** `docs/iteration_2/iteration_plan_and_roadmap.md` (Фаза 1)
*   **Библиотеки:** `whitenoise`, `secure`

## Подзадачи

1.  [ ] **Установка зависимостей**
    *   Добавить `whitenoise` и `secure` в `requirements.txt` (или `pyproject.toml`).
2.  [ ] **Настройка WhiteNoise**
    *   В `core/main.py`: Обернуть приложение (или настроить Middleware) для раздачи статики из папки `dist/` по пути `/desktop`.
    *   Убедиться в поддержке сжатия (Brotli/Gzip) и кеширования.
3.  [ ] **Динамическое монтирование плагинов**
    *   В `lifespan` (или при старте): Пройтись по `loader.loaded_plugins`.
    *   Если у плагина есть папка `ui`, смонтировать её как `StaticFiles` по пути `/plugins/{plugin_id}/ui`.
    *   *Важно:* Реализовать проверку существования папки во избежание ошибок.
4.  [ ] **Настройка CSP (Content Security Policy)**
    *   Использовать библиотеку `secure` для создания заголовков.
    *   **Policy:**
        *   `default-src 'self'`
        *   `script-src 'self' 'unsafe-inline' (для Svelte, если нужно) https://cdn.jsdelivr.net`
        *   `style-src 'self' 'unsafe-inline'`
        *   `frame-src 'self'` (для изоляции виджетов)
    *   Применить middleware к приложению.
5.  [ ] **Health Check для UI**
    *   Создать эндпоинт `GET /health/ui/{plugin_id}`.
    *   Проверять доступность `index.js` или `manifest.json` по смонтированному пути.

## Автоматические тесты
*   **Unit:** Проверка конфигурации CSP (наличие заголовков в ответе).
*   **Integration:** Тест, который "фейково" создает папку плагина, запускает приложение и проверяет, что файл доступен по `/plugins/fake/ui/test.txt`.

## Пункты самопроверки
*   [ ] Шелл открывается по `/desktop` (или редирект с `/`).
*   [ ] Заголовки ответа содержат `Content-Security-Policy`.
*   [ ] Статика плагинов доступна по URL.
*   [ ] При отсутствии папки `ui` приложение не падает при старте.

## Критерии выполнения (Definition of Done)
1.  Сервер запускается без ошибок.
2.  Статические файлы раздаются с заголовками кеширования.
3.  Заголовки безопасности (CSP) присутствуют.
4.  Все тесты (Unit + Integration) проходят.
