# Задача 1.2: UI-Registry и Валидация Плагинов (Phase 1)

**Цель:** Создать инфраструктуру для регистрации, валидации и хранения метаданных UI-компонентов (виджеты, кнопки, страницы) плагинов.

## Контекст
*   **Файлы:** `core/registry.py`, `core/loader.py`
*   **Документация:** `docs/iteration_2/iteration_plan_and_roadmap.md` (Фаза 1)
*   **Библиотеки:** `pydantic` (JSON Schema)

## Подзадачи

1.  [x] **Рефакторинг Registry**
    *   В `core/registry.py` добавить хранилище: `_ui_extensions: Dict[str, List[Dict]]`.
    *   Метод `register_ui_extension(plugin_id: str, data: Dict)`.
    *   Включить логирование регистрации.
2.  [x] **Рефакторинг Loader**
    *   В `core/loader.py` (`_load_plugin`) парсить `manifest.json`.
    *   Искать секции `widgets`, `shortcuts`, `views` или общую `ui`.
    *   Вызывать `registry.register_ui_extension` для найденных данных.
3.  [x] **Валидация Манифеста (Строгая)**
    *   Создать Pydantic-модель `PluginUI` в `core/schemas.py`.
        *   `widgets`: List[WidgetSchema]
        *   `views`: List[ViewSchema]
    *   Валидировать `manifest.json` перед загрузкой.
    *   **При ошибке:**
        *   Плагин помечать как `failed_validation`.
        *   Записывать ошибку в лог.
        *   Не загружать плагин, чтобы избежать runtime-ошибок.
4.  [x] **Health Checks для Реестра**
    *   Эндпоинт `GET /api/v1/registry/ui-extensions`.
    *   Возвращать JSON со списком всех зарегистрированных расширений, сгруппированных по ID плагина.

## Автоматические тесты
*   **Unit:** Создать тестовые манифесты (валидный, невалидный, пустой).
*   **Unit:** Проверить, что валидатор отбрасывает манифест с отсутствующими обязательными полями (напр. `id`, `version`).
*   **Integration:** Загрузить тестовый плагин и проверить, что данные появились в `registry._ui_extensions`.

## Пункты самопроверки
*   [x] Валидация JSON Schema работает (Pydantic выбрасывает ошибку на плохой манифест).
*   [x] Реестр корректно сохраняет данные UI.
*   [x] API возвращает правильный список расширений.

## Критерии выполнения (Definition of Done)
1.  Манифесты плагинов проходят строгую валидацию.
2.  Ошибочные манифесты блокируют загрузку плагина.
3.  API реестра доступен и возвращает корректные данные.
4.  Тесты проходят.
