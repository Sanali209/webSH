# Задача 3.2: Система рабочих столов и CRUD (Phase 3)

**Цель:** Реализовать логику управления несколькими рабочими столами (создание, удаление, переключение) и сохранения их состояния.

## Контекст
*   **Файлы:** `shell/src/lib/stores/ui.svelte.ts`, `shell/src/lib/services/uiManager.ts`, `core/main.py`
*   **Документация:** `docs/iteration_2/iteration_plan_and_roadmap.md` (Фаза 3)
*   **Библиотеки:** `lancedb` (или `sqlite` через ядро)

## Подзадачи

1.  [ ] **Backend: API Сохранения Состояния**
    *   В `core/main.py`: Эндпоинт `POST /api/v1/desktop/sync`.
    *   Принимать JSON: `desktops: List[DesktopConfig]`.
    *   Сохранять в `lancedb` (таблица `desktop_state`) или `sqlite` (через `system_storage`).
    *   **Fallback:** `GET /api/v1/desktop/sync`: Загружать при старте.
2.  [ ] **Frontend: Sidebar (Навигация)**
    *   В `shell/src/components/Sidebar.svelte`:
        *   Отображать список столов (`desktops: Desktop[]`).
        *   Добавить кнопку `+` для создания нового стола.
        *   Кнопку `x` для удаления стола (с подтверждением).
    *   Использовать `UIState` (Runes) для реактивного списка.
3.  [ ] **Frontend: CRUD Логика**
    *   В `shell/src/lib/services/uiManager.ts`:
        *   `addDesktop()`: Создать новый объект Desktop, добавить в массив, сохранить.
        *   `removeDesktop(id)`: Удалить, переключить на соседний, сохранить.
        *   `switchDesktop(id)`: Изменить `activeDesktop`.
    *   Вызывать API `sync` после каждого изменения.

## Автоматические тесты
*   **Integration (Backend):** Тест API `/desktop/sync` (сохранение и загрузка JSON).
*   **Unit (Frontend):** Тест `uiManager` (добавление стола увеличивает массив).
*   **E2E (Playwright):**
    1.  Загрузить Shell.
    2.  Нажать `+` (добавить стол).
    3.  Перезагрузить страницу.
    4.  Проверить, что столов все еще 2.

## Пункты самопроверки
*   [ ] Столы добавляются и удаляются корректно.
*   [ ] Активный стол подсвечивается в сайдбаре.
*   [ ] После перезагрузки страницы состояние восстанавливается.

## Критерии выполнения (Definition of Done)
1.  CRUD столов работает на фронтенде.
2.  Состояние персистентно сохраняется на бэкенде.
3.  UI сайдбара работает корректно.
4.  Тесты проходят.
