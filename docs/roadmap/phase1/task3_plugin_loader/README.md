# Task 1.3: Plugin Loader & Registry

## 1. Вводная часть
Перед началом исполнения: **изучить паттерн "Narrow Core Interface" и документацию Pluggy**.

## 2. Инструкция по выполнению
1. Реализовать `PluginManager` на базе **Pluggy**.
2. Создать механизм динамической загрузки из папки `/plugins`.
3. Реализовать "Направленный контракт": плагины могут взаимодействовать только через официально объявленные хуки ядру.
4. Регистрация метаданных плагина (версия, автор, необходимые Capability) в системном Registry.

## 3. Спецификация API (Integration Details)
- **Hookspec:** `sh_plugin_init(registry_ptr)`
- **Discovery:** Сканирование `__init__.py` в подпапках `/plugins`.
- **Validation:** Проверка `manifest.json` каждого плагина перед загрузкой.

## 4. Зависимости (Dependencies)
- `pluggy`, `importlib-metadata`.

## 5. Принципы кода и архитектуры
- [x] **Isolation:** Ошибка при загрузке одного плагина не должна останавливать ядро.
- [x] **Narrow Interface:** Плагины получают доступ только к ограниченному SDK, а не ко всему объекту приложения.
- [x] **Explicit Registration:** Каждый плагин должен явно задекларировать свои Capability.

## 6. Безопасность и Валидация
- Проверка структуры манифеста через Pydantic.
- Запрет загрузки плагинов без валидной подписи (в будущем) или обязательных полей.
