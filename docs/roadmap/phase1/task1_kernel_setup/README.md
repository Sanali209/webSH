# Task 1.1: Kernel Core & FastAPI Setup

## 1. Вводная часть
Перед началом исполнения: **детально изучить текущую архитектуру в `docs/DESIGN.md` и `docs/DESIGN_EXTENDED.md`**.

## 2. Инструкция по выполнению
1. Создать виртуальное окружение Python 3.11 (`python -m venv venv`).
2. Настроить файл `.gitignore` (исключить `venv/`, `__pycache__/`, `.env`, файлы данных БД).
3. Настроить базовое FastAPI приложение в `main.py`.
4. Подключить библиотеку **Rich** для стилизованного вывода в консоль при старте.
5. Организовать базовую структуру папок согласно `docs/DESIGN.md` (раздел 8).

## 3. Спецификация API (Integration Details)
- **Endpoints:**
    - `GET /health` — Статус системы.
    - `GET /api/v1/meta` — Метаданные ядра и список загруженных доменов.
- **Internal Hooks:** `on_startup`, `on_shutdown`.

## 4. Зависимости (Dependencies)
- `fastapi`, `uvicorn`, `rich`, `loguru`, `pydantic-settings`.

## 5. Принципы кода и архитектуры
- [ ] **Type Safety:** Использование Python 3.11+ Type Hints.
- [ ] **Async Native:** Все эндпоинты асинхронны.
- [ ] **Structured Logging:** Использование Loguru с поддержкой JSON-формата для продакшена.
- [ ] **Clean Startup:** Грейсфул-шатдаун и очистка ресурсов.

## 6. Безопасность и Валидация
- Настройка CORS middleware (строгие правила для локального хоста).
- Валидация переменных окружения через `Pydantic Settings`.

## 7. Самопроверка (Self-Review)
- [ ] Команда `pytest tests/test_kernel.py` проходит успешно.
- [ ] Логи при старте отображаются в Rich-панели.
- [ ] Отсутствуют висящие процессы после завершения.

## 8. План исполнения
1. [ ] Создание и активация `venv`, установка базовых зависимостей.
2. [ ] Создание `.gitignore`.
3. [ ] Инициализация `main.py`.
4. [ ] Настройка middleware и логгера.
5. [ ] Реализация эндпоинта `/health`.

## 9. Цели готовности (Definition of Done)
- [ ] Сервер запускается и отвечает на пинг.
- [ ] Rich-консоль выводит приветствие и версию ОС.
- [ ] Код прошел проверку `ruff` или `flake8`.
