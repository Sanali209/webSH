# Task 4.1: System Executor (Taskiq)

## 1. Вводная часть
Перед началом исполнения: **изучить роль Executor в `docs/DESIGN.md` раздел 5.2**.

## 2. Инструкция по выполнение
1. Реализовать плагин `system_executor` на базе **Taskiq**.
2. Настроить ZeroMQ как транспорт для задач.
3. Реализовать Capability `core.execute`, принимающую параметры функции и контекста.
4. Обеспечить публикацию события `task.finished` после завершения.

## 3. Спецификация API (Integration Details)
- **Signal In:** `core.execute(func_name, params, priority)`
- **Signal Out:** `task.finished(correlation_id, status, result)`
- **Background Worker:** Отдельный процесс с поддержкой горячей перезагрузки.

## 4. Зависимости (Dependencies)
- `taskiq`, `pyzmq`, `taskiq-dependencies`.

## 5. Принципы кода и архитектуры
- [ ] **Non-blocking Dispatch:** Ядро не ждет ответа от экзекутора; ответ идет через событие в Шину.
- [ ] **Task Isolation:** Каждая задача выполняется в своем контексте.
- [ ] **Backpressure Control:** Лимиты на количество одновременно выполняемых тяжелых задач.
- [ ] **State Preservation:** Возможность передачи стейта для долгих задач.

## 6. Безопасность и Валидация
- Проверка сигнатур вызываемых функций (Whitelist).
- Таймауты на выполнение (Hard killing зависших воркеров).

## 7. Самопроверка (Self-Review)

- [ ] После закрытия ядра все воркеры Taskiq корректно завершаются.
