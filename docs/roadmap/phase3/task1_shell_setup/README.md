# Task 3.1: System Shell Setup

## 1. Вводная часть
Перед началом исполнения: **изучить новую систему реактивности Svelte 5 (Runes) в `docs/DESIGN.md` раздел 5.3**.

## 2. Инструкция по выполнению
1. Инициализировать проект на **Svelte 5 + Vite**.
2. Внедрить глобальное состояние через `$state` руны для управления активным рабочим столом и списком уведомлений.
3. Настроить базовый лейаут: Sidebar, TopBar, MainViewport.
4. Обеспечить интеграцию с Ядром через Axios/Fetch и WebSocket для получения реальных событий.

## 3. Спецификация API (Integration Details)
- **State:** `$state({ active_desktop: 1, overlays: [] })`.
- **Backend API:** `GET /api/v1/plugins` (для загрузки списка виджетов).

## 4. Зависимости (Dependencies)
- `svelte@next`, `vite`, `lucide-svelte`.

## 5. Принципы кода и архитектуры
- [ ] **Rune-based Reactivity:** Никаких `writable` сторов; использование только `$state` и `$derived`.
- [ ] **Explicit Props:** Использование `$props()` для передачи данных в компоненты.
- [ ] **Theming:** Использование CSS переменных для поддержки Dark/Light режимов.

## 6. Безопасность и Валидация
- Настройка CSP (Content Security Policy) для ограничения загрузки скриптов.
- Санитизация любых данных, вставляемых через `{@html}` (использовать только в крайних случаях).

## 7. Самопроверка (Self-Review)
- [ ] Команда `npm run dev` запускает чистую оболочку.
- [ ] Переключение рабочих столов (1-5) меняет переменную в глобальном стейте.

## 8. План исполнения
1. [ ] Инициализация Vite-Svelte.
2. [ ] Создание архитектуры папок `/src/lib/components`.
3. [ ] Реализация навигации.

## 9. Цели готовности (Definition of Done)
- [ ] Скелет ОС готов.
