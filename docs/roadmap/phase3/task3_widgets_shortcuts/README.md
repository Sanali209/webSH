# Task 3.3: Widget & Shortcut Logic

## 1. Вводная часть
Перед началом исполнения: **изучить контракт виджетов в `docs/DESIGN_EXTENDED.md` раздел 3.3**.

## 2. Инструкция по выполнению
1. Реализовать компонент `WidgetWrapper.svelte`, который отрисовывает UI плагина внутри ячеек сетки.
2. Реализовать компонент `Shortcut.svelte` для иконок быстрого запуска.
3. Организовать передачу `grid_size` от плагина к Шеллу для корректного резервирования места в сетке.

## 3. Спецификация API (Integration Details)
- **Widget Contract:**
    - `manifest: { ui: { widget: { component: "path/to/Svelte", grid_size: [w, h] } } }`
- **Shortcut Action:** `pc_center.call("shell.exec", { target: shortcut.ref })`
- **Loading State:** Скелетный загрузчик (Skeleton) пока компонент не подгружен.

## 4. Зависимости (Dependencies)
- Динамический ESM импорт браузером.

## 5. Принципы кода и архитектуры
- [ ] **Sandboxed Styles:** Использование Shadow DOM или уникальных CSS-классов для изоляции стилей виджета.
- [ ] **Lazy Hydration:** Загрузка JS-кода виджета только когда пользователь находится на этом рабочем столе.
- [ ] **Generic Wrappers:** Обертка виджета должна рисовать заголовок и кнопку "настройки/удаления".
- [ ] **Strict Typing:** Соблюдение контракта пропсов между Шеллом и Виджетом.

## 6. Безопасность и Валидация
- Ограничение доступа виджета к глобальному объекту `document` (через паттерны изоляции).
- Обработка ошибок в жизненном цикле виджета (Boundary Error).

## 7. Самопроверка (Self-Review)
- [ ] Виджет 3x2 занимает ровно 6 ячеек сетки.
- [ ] При падении кода виджета, остальной Шелл продолжает работать.

## 8. План исполнения
1. [ ] Проектирование Wrapper-а.
2. [ ] Система подгрузки удаленных модулей.
3. [ ] Реализация стандартного Shortcut компонента.

## 9. Цели готовности (Definition of Done)
- [ ] Интерактивные виджеты работают на рабочем столе.
- [ ] Ярлыки успешно шлют сигналы на бэкенд.
- [ ] Выполнен рендер-тест с 20+ ярлыками.
