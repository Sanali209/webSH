# Task 3.3: Widget & Shortcut Logic

## 1. Вводная часть
Перед началом исполнения: **изучить манифест плагинов и способ подгрузки UI компонентов в `docs/DESIGN.md` раздел 9**.

## 2. Инструкция по выполнению
1. Реализовать систему динамической подгрузки виджетов через **Vite Dynamic Imports**.
2. Использовать `{#await}` для обработки состояний загрузки (Loading/Error skeleton).
3. Создать логику ярлыков (Shortcuts), которые запускают Capability при двойном клике.

## 3. Спецификация API (Integration Details)
- **Dynamic Load:** `const module = await import(`/plugins/${name}/index.js`)`.
- **Props:** Передача `call` и `emit` методов Ядра в веб-компонент виджета.

## 4. Зависимости (Dependencies)
- `lucide-svelte` (иконки для ярлыков).

## 5. Принципы кода и архитектуры
- [ ] **Code Splitting:** Каждый виджет — это отдельный JS чанк.
- [ ] **Sandboxing:** Изучить возможность изоляции стилей виджета через Shadow DOM.
- [ ] **Lazy Initialization:** Виджет инициализируется только когда его рабочий стол становится активным.

## 6. Безопасность и Валидация
- Проверка доверенного источника (Trusted source) перед динамическим импортом.
- Изоляция JS контекста через ограниченные пропсы.

## 7. Самопроверка (Self-Review)
- [ ] Клик по ярлыку вызывает Capability в Ядре (проверить в терминале).
- [ ] Виджеты загружаются асинхронно, не блокируя UI.

## 8. План исполнения
1. [ ] Реализация загрузчика компонентов.
2. [ ] Верстка базового виджета-контейнера.
3. [ ] Логика ярлыков.

## 9. Цели готовности (Definition of Done)
- [ ] Динамическая система плагинов работает в браузере.
- [ ] Ярлыки корректно привязаны к Capability.
