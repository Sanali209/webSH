# Task 3.4: Slot Registry (UI Injection)

## 1. Вводная часть
Перед началом исполнения: **изучить систему слотов в `docs/DESIGN_EXTENDED.md` раздел 3**.

## 2. Инструкция по выполнению
1. Реализовать реестр визуальных слотов (например, `topbar.right`, `sidebar.bottom`).
2. Использовать **Svelte 5 Snippets** для эффективной передачи UI блоков от плагинов в систему.
3. Поддерживать приоритеты (Priority) для компонентов в одном слоте.

## 3. Спецификация API (Integration Details)
- **Registry:** `Map<slot_name, Component[]>`
- **Snippet Call:** `{@render slot_snippet(data)}`.

## 4. Зависимости (Dependencies)
- Svelte 5 Native.

## 5. Принципы кода и архитектуры
- [ ] **Pluggable UI:** Главная оболочка не знает о количестве кнопок в сайтбаре; она просто рендерит массив из слота.
- [ ] **Fine-grained Updates:** Использование сигналов Svelte 5 для обновления только конкретного слота при регистрации нового плагина.
- [ ] **Default Content:** Поддержка fallback-контента, если слот пуст.

## 6. Безопасность и Валидация
- Ограничение количества компонентов в одном слоте (защита от UI спама).
- Проверка совместимости типов пропсов для сниппетов.

## 7. Самопроверка (Self-Review)
- [ ] Плагин "System Inspector" успешно добавляет иконку в `sidebar.bottom`.
- [ ] Порядок кнопок соответствует заданным приоритетам.

## 8. План исполнения
1. [ ] Создание Registry стора для слотов.
2. [ ] Внедрение Snippet-логики в основной лейаут.
3. [ ] API для плагинов для "впрыска" в слот.

## 9. Цели готовности (Definition of Done)
- [ ] Система инъекции UI работает.
- [ ] Оболочка стала полностью расширяемой.
