# Task 3.2: Desktop Grid Engine

## 1. Вводная часть
Перед началом исполнения: **изучить систему координат 12x8 в `docs/DESIGN_EXTENDED.md` раздел 3.3**.

## 2. Инструкция по выполнению
1. Реализовать сетку рабочего стола с использованием **CSS Grid**.
2. Создать компонент `GridCell`, поддерживающий координаты `x, y`.
3. Интегрировать библиотеку для Drag-and-Drop, совместимую с Svelte 5 (рекомендуется `@thisux/sveltednd`).
4. Поддерживать 5 независимых рабочих столов с сохранением позиций виджетов.

## 3. Спецификация API (Integration Details)
- **Grid Layout:** `grid-template-columns: repeat(12, 1fr); grid-template-rows: repeat(8, 1fr);`
- **Component Prop:** `{ x: number, y: number, w: number, h: number }`.

## 4. Зависимости (Dependencies)
- `@thisux/sveltednd` (или `dnd-kit-svelte`).

## 5. Принципы кода и архитектуры
- [ ] **Declarative Layout:** Сетка не перерисовывается целиком при движении виджета; обновляются только CSS классы соседних ячеек.
- [ ] **Collision Detection:** Виджеты не могут перекрывать друг друга (логика смещения или блокировки).
- [ ] **Responsive Cells:** Квадратные ячейки, адаптирующиеся под размер экрана.

## 6. Безопасность и Валидация
- Валидация координат виджета (не должен выходить за границы 12x8).
- Запрет на создание виджетов нулевого размера.

## 7. Самопроверка (Self-Review)
- [ ] Виджет можно перетащить из (0,0) в (5,5).
- [ ] При смене рабочего стола виджеты мгновенно обновляются.

## 8. План исполнения
1. [ ] Верстка CSS Grid.
2. [ ] Реализация логики Drag-and-Drop.
3. [ ] Система сохранения координат в локальный стейт.

## 9. Цели готовности (Definition of Done)
- [ ] Рабочий стол функционален.
- [ ] Drag-and-Drop работает плавно и без багов.
