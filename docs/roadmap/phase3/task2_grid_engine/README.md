# Task 3.2: Desktop Grid Engine

## 1. Вводная часть
Перед началом исполнения: **изучить описание Desktop Grid System в `docs/DESIGN_EXTENDED.md` раздел 3.3**.

## 2. Инструкция по выполнению
1. Реализовать компонент `GridContainer.svelte`, отображающий сетку ячеек (напр. 12x8).
2. Разработать систему координат [x, y] для размещения элементов.
3. Добавить визуальную поддержку "пустых" ячеек и возможности перетаскивания (Drag & Drop) в будущем.

## 3. Спецификация API (Integration Details)
- **Model:** `DesktopConfig { id: int, grid: [cols, rows], items: List[GridItem] }`
- **GridItem:** `{ x: int, y: int, w: int, h: int, type: str, ref: str }`
- **Internal State:** `ui.desktops` в Shared Store.

## 4. Зависимости (Dependencies)
- `svelte-gestures` (опционально для тач-скринов).

## 5. Принципы кода и архитектуры
- [ ] **Mathematical Layout:** Рассчитывать размер ячейки на базе `containerWidth / cols`.
- [ ] **Overlap Prevention:** Алгоритм проверки пересечений при размещении новых элементов.
- [ ] **Immutability:** Обновление карты стола через замену всего массива (best for Svelte reactivity).
- [ ] **Pixel Perfect:** Использование `aspect-ratio` для квадратных ячеек.

## 6. Безопасность и Валидация
- Проверка выхода за границы сетки (Out of bounds).
- Валидация JSON-схемы конфигурации столов.

## 7. Самопроверка (Self-Review)
- [ ] Сетка 12x8 корректно вписывается в экран 1920x1080 и 1366x768.
- [ ] Переключение столов мгновенно меняет набор элементов на сетке.

## 8. План исполнения
1. [ ] Grid Layout CSS.
2. [ ] Менеджер состояния столов.
3. [ ] Логика позиционирования элементов.

## 9. Цели готовности (Definition of Done)
- [ ] 5 независимых столов с уникальными сетками.
- [ ] Placeholder-компоненты занимают правильные ячейки.
- [ ] Код готов к приему реальных виджетов.
