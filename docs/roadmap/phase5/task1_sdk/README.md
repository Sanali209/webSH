# Task 5.1: Plugin SDK & Decorators

## 1. Вводная часть
Перед началом исполнения: **изучить паттерн декларативной регистрации через декораторы классов/методов в Python**.

## 2. Инструкция по выполнению
1. Реализовать абстрактный класс `BasePlugin`.
2. Создать декоратор `@capability(name, schema?)`, который при инициализации плагина автоматически регистрирует метод в Switchboard.
3. Добавить декоратор `@on_event(pattern)` для подписки на события Шины.
4. Реализовать методы-хелперы: `self.call()`, `self.emit()`, `self.get_state()`.

## 3. Спецификация API (Integration Details)
- **SDK Class:** `core.sdk.BasePlugin`.
- **Registration:** Использование `inspect.getmembers()` для автоматического обнаружения декорированных методов.

## 4. Зависимости (Dependencies)
- `inspect`, `functools`.

## 5. Принципы кода и архитектуры
- [x] **Declarative API:** Разработчик плагина должен писать минимум инфраструктурного кода.
- [x] **Type Hinting:** Полная поддержка статического анализа типов для передаваемых параметров.
- [x] **Plugin Lifecycle:** Методы `on_activate()` и `on_deactivate()` для инициализации ресурсов.

## 6. Безопасность и Валидация
- Проверка уникальности имен Capability при регистрации в рамках одного плагина.
- Валидация сигнатур (наличие `ctx` аргумента в каждом `@capability`).
