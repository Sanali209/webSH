💡 Ключевые концепции

  1. Capability Broker: FastAPI kernel routing requests to plugins via domain@version
  2. Plugin SDK: @capability декоратор + BasePlugin + Pluggy hook system
  3. Schema Guard: Pydantic TypeAdapter для high-speed валидации параметров
  4. Trace Stack: Circular dependency detection через trace_stack в Context
  5. Taskiq + Redis: Фоновая очередь с worker и callback через HTTP loopback
  6. OpenTelemetry + Jaeger: Full tracing pipeline + WebSocket real-time broadcast
  7. LanceDB: Встраиваемая векторная БД для desktop state и storage plugin
  8. Shared Memory IPC: multiprocessing.shared_memory для cross-process данных
  9. UI Extension Slots: widgets/views/shortcuts/top_bar — Svelte динамически загружает компоненты
  10. Path Sandbox: FS plugin проверяет path на выход за пределы workspace
