Шаг 13/14

📊 SWOT + Tech Debt + Roadmap

✅ Strengths

  • Чистая capability broker архитектура
  • Plugin SDK с @capability decorator
  • OpenTelemetry интеграция из коробки
  • Docker-first деплой
  • Хорошая документация (Diátaxis)
  • Security-first (CSP, sandbox, whitelist)
  • Async-first с Taskiq

❌ Weaknesses

  • Нет тестов
  • Нет auth/аутентификации
  • WebSocket /ws — не используется
  • Event system — не реализован
  • Callback через HTTP loopback
  • Desktop sync — полный оверрайт

🌍 Opportunities

  • Auth (JWT + Context.token)
  • Real-time event bus (Redis PubSub)
  • Plugin settings UI из JSON schema
  • Multi-desktop support
  • Визуальный plugin editor
  • AI integration через system_executor

⚠️ Threats

  • Конкуренция: Nextcloud, ownCloud web
  • Svelte 5 — новое API, мало материалов
  • LanceDB — нишевый, маленькое комьюнити
  • Taskiq — менее популярен, чем Celery
  • Проект может не найти adoption
