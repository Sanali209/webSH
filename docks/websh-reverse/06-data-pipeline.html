🔀 Data Pipeline — Capability Broker Chain

Pipeline Flow

Svelte Frontend / External Client
    │
    ▼ POST /api/v1/call { domain, params, context }
Switchboard.dispatch()
    ├─ 1. Trace depth check (max 10)
    ├─ 2. Push to trace_stack
    ├─ 3. Registry.resolve(domain) → handler
    ├─ 4. Schema Guard (TypeAdapter validation)
    ├─ 5. Execute handler(params, context)
    └─ 6. Return { status, data } or { status, error }
    │
    ▼
Plugin Handler (e.g. fs.list, hello.ping)
    │
    ▼ Optional: Taskiq Worker
    core.execute → Redis Queue → Worker → Callback via HTTP loopback

📡 Pipeline Stages

1. API Gateway

FastAPI POST /api/v1/call — единая точка входа. CORS, CSP, security headers.

2. Switchboard Dispatch

Pydantic validation envelope → trace depth check → Registry resolve → Schema Guard (TypeAdapter) → handler execution.

3. Registry Resolution

Registry хранит domain@version → handler mapping. Поддерживает latest version resolution.

4. Plugin Execution

Handler из плагина выполняется async. Может вызвать другие capability через self.call().

5. Taskiq Background Queue

system_executor → generic_executor_task.kiq() → Redis → Worker → HTTP callback task.finished.

6. OpenTelemetry Tracing

OTEL SpanProcessor экспортирует spans в Jaeger + WebSocket broadcast для live debugging.

7. Desktop State Sync

LanceDB хранит DesktopConfig. Полный оверрайт при POST, чтение при GET.
