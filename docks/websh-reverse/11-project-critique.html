🔬 Project Critique [WEB]

❓ Open Questions

1. Почему WebSocket /ws не подключён к Switchboard?

Гипотеза: Незавершённая фича. WebSocket только echo. Возможно, планировался real-time event bus.

2. Event system — on_event декоратор без реализации?

Гипотеза: SDK включает @on_event, но subscription не реализован. Планировался Redis PubSub.

3. Почему нет тестов?

Гипотеза: Проект в ранней стадии (iteration 2). pytest и pytest-asyncio в зависимостях, но тестов нет.

👁️ Blind Spots

  • Security: Нет auth. Context.token не проверяется. CORS allow_origins=["*"]
  • Error Handling: Воркер callback через HTTP — нет ретраев, может потерять task.finished
  • Memory: Shared memory сегменты не имеют ограничения по размеру/количеству
  • Persistence: Desktop state — полный оверрайт при POST, нет merge
  • Concurrency: ThreadPoolExecutor в system_fs не имеет ограничения размера

⚖️ Criticism

1. Callback через HTTP loopback — хрупкий

task.finished отправляется HTTP POST на localhost. Если сервер упал — потеря回调. Альтернатива: Redis PubSub или прямой вызов Switchboard.

2. Desktop sync — полный оверрайт

POST /api/v1/desktop/sync заменяет всю таблицу. Нет diff/merge. Альтернатива: PATCH с конкретными изменениями.

3. Нет тестовой инфраструктуры

pytest в зависимостях, но тестов нет. Критично для plugin-архитектуры.
