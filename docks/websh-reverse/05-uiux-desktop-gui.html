🪟 UI/UX — Web Desktop Environment

🖥️ Экраны

  • Desktop (Grid) — рабочее пространство с виджетами (позиционирование x,y,w,h)
  • Top Bar — верхняя панель с элементами от плагинов
  • Application Views — полноэкранные приложения
  • Widget Windows — плавающие окна виджетов
  • Shortcut Icons — ярлыки на рабочем столе

🎨 UX Patterns

  • Grid-based Layout: DesktopConfig хранит позиции виджетов, синхронизируется с LanceDB
  • Dynamic Component Injection: Svelte загружает компоненты плагинов из внешних entry_point
  • State Sync: POST/GET /api/v1/desktop/sync — полный оверрайт состояния
  • UI Extension Slots: 4 предопределённых слота для расширения интерфейса
