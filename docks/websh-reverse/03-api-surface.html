🛡️ Middleware

  • CORS: allow_origins=["*"] (dev mode)
  • CSP: Content-Security-Policy, script_src включает cdn.jsdelivr
  • Secure Headers: PermissionsPolicy, HSTS, XContentTypeOptions, ReferrerPolicy, XFrameOptions
  • WhiteNoise: serves frontend from /desktop
  • ORJSONResponse: быстрые JSON ответы

📦 Static Mounts

  • /plugins/{id}/ui — UI assets каждого плагина
  • /desktop — Svelte 5 build (dist/)
