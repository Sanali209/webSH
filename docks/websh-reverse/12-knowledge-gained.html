📐 Capability Broker на FastAPI

Pattern: Единый POST /api/v1/call маршрутизирует все вызовы. Switchboard + Registry = lightweight message broker.

Применимость: Plugin-based systems, микросервисы, Web OS.

🔄 TypeAdapter для Schema Guard

Lesson: Вместо Pydantic model validation (медленно), кэшированный TypeAdapter с validate_python().

Применимость: Высоконагруженные API с runtime-валидацией.

🔌 Pluggy + @capability decorator

Pattern: Pluggy hook specs для plugin lifecycle + @capability декоратор для авто-регистрации. BasePlugin.sh_plugin_init сканирует методы.

Применимость: Любая plugin-архитектура на Python.

🌊 OTEL + WebSocket real-time traces

Pattern: Custom SpanProcessor → broadcaster.broadcast() → WebSocket clients. Live debugging без Jaeger UI.

Применимость: DevOps дашборды, live debugging tools.

⚠️ HTTP loopback для task callback — anti-pattern

Anti-pattern: Worker HTTP POST на localhost для результата. Хрупко, нет ретраев, SPOF.

Альтернатива: Redis PubSub, Switchboard через import.

🔒 Path Sandbox в системе файлов

Pattern: os.path.abspath + startswith(root_dir) для предотвращения directory traversal.

Применимость: Любая файловая система с мульти-арендой.

📦 Multi-stage Docker + Svelte + FastAPI

Tool: Stage 1: Node build Svelte → dist. Stage 2: Python runtime + dist. Единый образ.
