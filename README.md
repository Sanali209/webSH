# PC Center

A modular local 'Web OS' application with a Python backend and Svelte frontend, designed to give you powerful tools for managing your computer directly from a web browser.

## Documentation

*   **[User Guide](docs/USER_GUIDE.md)**: Installation, usage, and features.
*   **[Developer Guide](docs/DEVELOPER_GUIDE.md)**: Architecture, plugin development, and contributing.

## Features

*   **System Dashboard**: Real-time resource monitoring.
*   **File Explorer**: Browse and manage local files.
*   **Web Parser**: Archive and search web pages offline.
*   **File Deduplicator**: Find and remove duplicate files.
*   **Script Engine**: Automate workflows with a visual editor.
*   **LLM Integration**: Chat with local AI models.

## Quick Start

### Prerequisites

*   Docker Desktop

### Running the Application

1.  Clone the repository:
    ```bash
    git clone https://github.com/yourusername/pc-center.git
    cd pc-center
    ```

2.  Start with Docker Compose:
    ```bash
    docker-compose up --build
    ```

3.  Open your browser:
    `http://localhost:5173`
